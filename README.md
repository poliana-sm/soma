# soma

projeto desenvolvido durante os estudos de JavaScript para praticar conceitos básicos de variáveis, funções, operações matemáticas e manipulação do DOM.

## funcionalidade

- possui um botão para exibir o resultado de uma operação matemática;
- utiliza JavaScript para realizar a soma de dois valores;
- exibe o resultado diretamente na página.

atualmente, ao clicar no botão "Mostrar Resultado", o projeto realiza a soma de 10 + 80 e exibe o resultado 90.

## tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## objetivo

praticar conceitos básicos de JavaScript, como declaração de variáveis, funções, operações matemáticas e manipulação de elementos HTML por meio do DOM.
